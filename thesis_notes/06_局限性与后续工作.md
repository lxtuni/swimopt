# 06 局限性与后续工作

## 6.1 模型能说明什么、不能说明什么

**能说明（定性）：**
- 在给定的水动力模型与舵机约束下，不同步态族、不同推进机制之间的相对优劣与趋势。
- 约束（平稳限值、舵机限速、出水比例）如何改变最优步态。
- 升力项加入后，最优解的推进机制会整体转向升力型。

**不能说明（定量）：**
- 真实机器人的绝对速度与功率。所有系数（Cd、Ca、cv、cl）都是文献/教科书值，**没有标定**。
- 电功率与续航：功率是电机输出轴机械功率，不含铜损和驱动器损耗。
- 非定常流体效应：涡脱落、尾流捕获、延迟失速等真实脚蹼可能依赖的机制，模型里都没有，可能使结论往任一方向变化。
- 自由液面：波浪阻力、飞溅都没有。肢体出水的步态不可信（已用出水比例监控/约束）。
- 真实实物：模型是 toy_quad，不是 BODY2。

## 6.2 需要在论文里明说的限制（每个结果都依附的条件）

| 限制 | 影响 |
|---|---|
| `cl = 1.1` 未标定 | 升力相关结论只具定性意义 |
| 附加质量各向同性近似 | 真实附加质量强烈各向异性（尤其薄板），影响加速阶段 |
| 舵机模型无发热 | 多数最快步态舵机全程处于力矩上限，真实舵机会过热降额 |
| 频率上限 2.5 Hz | 最快的 bound 顶在上限，上限应按真实舵机能持续的频率设 |
| 优化未完全收敛 | 所有数字是模型允许值的**下界**（最快）或**上界**（最小功率）；种子间离散大 |
| 每条件种子数 2–3 | 许多差异处于离散之内，只能称"趋势" |
| 自由相位 35 维搜索效率低 | 不能用它的结果否定任何协调方式 |
| 约束塑造答案 | 多数最优解卡在某个限值上，必须连同限值一起报告 |

## 6.3 建议的后续工作（按对论文的价值排序）

1. **标定**：
   - 脚蹼 `cl`、`Cd`：拖曳/摆动实验测力；
   - 整机：滑行减速（coast-down）得阻力，静吃水得浮力体积，摆动衰减得附加质量；
   - 双足划水等简化构型验证推力。
   标定完成后重跑实验 3 和 4，才能给定量结论。
2. **收敛性**：每个条件增加种子数（≥ 5）或评估次数，或在同一条件下做内置重启（CMA-ES restarts / IPOP）。
3. ~~同速度比较对角步态~~ 已完成（04 文件 4d）。下一步改为：**同一模型内比较升力型与阻力型步态**——在含升力的模型里给优化加"升力冲量占比 ≤ 阈值"的约束，强制搜出阻力型步态，再与升力型步态同速比功率。这才是"升力型划水更优"的直接证据，比跨模型比值更有说服力。
3b. **电功率指标**：现在的功率是电机输出轴机械功率，忽略铜损。用已有的电机模型可推出 `P_电 = τω + τ²·ωmax/ts`，不需要新参数；堵转时每个舵机约 21 W，会大幅改变"全程饱和"步态的耗能排名。对所有已有最优解事后重算即可，不必重新优化。
4. **系数敏感性**：cl、Cd、Ca 各 ±50%，看结论（升力更省、对角步态最省）是否翻转。
5. **BODY2 实物模型**：重新导入 URDF（全部销轴为 revolute），用 `<equality><connect>` 闭合平行四边形连杆；
   检查只有一个主动关节、脚蹼被动时二次谐波是否必要。
6. **硬件轨迹导出**：把最优参数转换为舵机指令序列（含频率、占空比、相位），在实物上验证。
7. **舵机发热/功率降额模型**：限制持续力矩，避免"全程饱和"的解。
8. **水下 vs 水面**：确认论文场景是水面划水还是潜航，决定自由液面效应是否必须建模。
