# 07 复现指南

在仓库根目录 `swimopt/` 下运行。Windows 本机用 `mjenv\Scripts\python.exe`；新机器先 `pip install -r requirements.txt`。
所有实验都会跳过已完成的运行（按预算判断），中断后重跑即可续上。
16 核笔记本上每次运行（2500 次评估）约 4–5 分钟。**长时间实验时请插电、不合盖**，否则睡眠会暂停计算。

## 基本操作

```bash
python view.py config.json --demo                  # 看手工步态
python optimize.py config.json 2500                # 按 config.json 寻优，结果写入 results/
python view.py config.json results/best.json       # 看最优结果
python ui.py                                       # 图形控制面板
python -m pytest                                   # 66 个测试
```

`results_*` 文件夹不在 git 里（`.gitignore`），只在本机。每个运行子文件夹含：
`_cfg.json`（该运行的完整配置）、`best.json`/`done.json`（最优参数向量 + 全部指标）、
`log.csv`（每次评估）、`convergence.json`（每代最优与 σ）、`run_config.json`（库版本）。

## 分析与出图

```bash
python tools/describe_gait.py results_families/fb_s1/best.json                     # 步态结构 + 步态图
python tools/describe_gait.py results_families_lim10-5-5_lift/diag_s2/best.json --lift --out docs/x.png
python tools/render_media.py --gait results_families/fb_s1/best.json --stem gait_optimized
python tools/render_media.py --gait <路径>/best.json --stem 名字 --lift          # 升力物理下渲染
python tools/render_media.py --panel --run 2500 --seed 1 --family fb             # 控制面板截图（需桌面）
python thesis_notes/export_data.py                                                 # 重新生成 data/all_runs.csv
```

注意：回放升力物理下优化出的结果时必须加 `--lift`，否则它会在阻力物理下被评估，表现完全不同。

## 修改实验条件

所有可调参数在 `config.json`，关键项：

| 想改 | 字段 |
|---|---|
| 升力开关 | `hydro.lift` |
| 水动力系数（标定后填） | `hydro.rules[].cd / ca / cv / cl` |
| 舵机空载转速 | `servo.max_speed_dps`（null = 不限） |
| 平稳限值 | `limits.heading_deg / roll_deg / pitch_deg`；出水上限 `limits.surfacing` |
| 目标 | `objective.mode`（speed / power），`objective.min_speed` |
| 步态族 | `gait.family`（null = 自由相位；trot/pace/bound/walk/pronk） |
| 频率上限 | `gait.freq_range` |
| 预算、种群、种子 | `budget`，`popsize`，`seed`（非零） |
