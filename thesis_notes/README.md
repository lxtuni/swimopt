## 一页结论（截至 2026-09-30）

1. **管线可用且可复现。** 任意 MuJoCo/URDF 机器人 → Morison 型水动力 → 傅里叶步态 → CMA-ES 寻优。
   相同种子逐位复现；并行与串行结果完全相同；66 个自动化测试在 Windows/Ubuntu、Python 3.11/3.12 上通过。
2. **舵机转速限制是必要的物理约束。** 不限速时优化器要求关节 2700–4200 °/s，是舵机能力的 5–10 倍；
   把那样的步态放到 400 °/s 舵机上，前进速度约为 0。之后所有有效结果都用 400 °/s 的直流电机力矩-转速模型。
3. **步态族对比（仅阻力，平稳限值 横滚 10°/俯仰 15°）：bound（前后跳跃）最快**，0.481 ± 0.034 m/s（3 个种子），
   明显快于 trot/pace/walk（约 0.34 m/s）和 pronk（0.27 m/s）。
4. **升力型 vs 阻力型，在相同速度下比功率：有升力时所需功率在三个速度上都更低**
   （0.10/0.20/0.30 m/s 时比值 0.43/0.53/0.31）。只要模型含升力，所有合格最优解都是升力推进、阻力为纯损耗。
   比值的具体大小不可靠（搜索未完全收敛），方向可靠。
5. **收紧平稳限值（横滚/俯仰 5°）+ 升力时：** bound 仍最快（0.295 ± 0.139 m/s，最高 0.48）。
   同速度比最小功率（5 个种子）：低速 ≤ 0.15 m/s 时对角步态（trot）与 bound 相近、略省；0.20 m/s 时 bound/pronk 约省一半，
   trot 已接近其速度上限。**"对角步态更节能"只在低速段弱成立，不是强结论。**
   预算 10000 次的自由搜索三次都收敛到 bound/pronk 类协调（0.22–0.37 m/s），"不预设时自发出现对角步态"的说法撤回。见 04 文件实验 4d、4e。
6. **最大的不确定性：`cl`（升力系数）未标定，水动力系数都是文献值；** 所有结论都是"在本模型中"的定性结论，
   定量结论需要实测脚蹼与整机标定。

## 写论文时的几条规则

- 报告物理量（m/s、体长/秒、W、J/m、度），**不要报告 fitness 数值**，它在不同设置之间不可比。
- 每个数字都要说明：物理（仅阻力 / 阻力+升力）、约束（限值）、舵机限速、种子数、评估次数。
- 2026 年 9 月之前 README 中的数字、以及舵机模型之前的"阻力 vs 升力 2×2"数字**全部撤回**，见 05 文件。
- 模型里的机器人是 toy_quad（开源的小四足），**不是**实验室的 BODY2 实物模型；BODY2 的 CAD 不在仓库中。
